## 核验说明

- `official-url-verified`：附件提供了可核验的 arXiv 标识和官方地址。
- `citation-metadata-reviewed`：已逐条检查作者、标题、出处和年份，并与仓库标题、arXiv ID 及规范化标题比对；未找到可靠 DOI/官方页面时不补造链接。
- 同一论文的标题截断、标点差异及预印本/正式版差异优先判为仓库已存在，不重复新增。
