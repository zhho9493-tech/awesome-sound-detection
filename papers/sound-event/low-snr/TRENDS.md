# 低信噪比 SED 技术趋势与依据（2025–2026）

## 总趋势
**被动噪声增强 → 目标条件分离 → 动态时频建模与噪声感知表征 → 事件级约束和可靠性评估。** 这是对不同技术主线的研究归纳，并非所有论文按此顺序演进。

| 差距 | 方法方向 | 2025–2026 代表性依据 | 限制 / 验证要求 |
|---|---|---|---|
| 目标被背景掩蔽 | 文本/事件条件分离 | [TQ-SED](https://doi.org/10.1109/ICASSP49660.2025.10889789)、[EAD-SED](https://arxiv.org/abs/2508.07176) | 目标不存在时测试假阳性、Clean 输入退化 |
| 固定卷积难捕捉弱目标 | 动态时频卷积和跨频带对齐 | [DTFP](https://doi.org/10.1109/TASLPRO.2026.3678192)、[DAAPNet](https://doi.org/10.1109/TASLPRO.2026.3651989) | 同主干公平对比，按短/长事件分析 |
| 模型学习背景快捷方式 | 噪声感知表征 / 双视角训练 | [DCASE 2026 论文集（NA-SSL, ASD）](https://dcase.community/workshop2026/proceedings) | 邻接任务证据，不可直接声称 SED 有效 |
| 分离产生伪目标 | 目标与噪声语义锚点、存在性约束 | [DCASE 2026 Text Anchors](https://dcase.community/workshop2026/proceedings) | 评估 no-target 强噪声负样本 |
| 离线合成结果虚高 | 真实噪声 / 跨站点 / 固定阈值验证 | [DCASE 2026 论文集](https://dcase.community/workshop2026/proceedings) | 项目、时间、声源录音完全隔离 |

## 可直接引用的量化证据
- DTFP（2026）在 −10 到 −5 dB 条件，作者报告 PSDS 对比 Conformer 和 CRNN 分别提升 **9.4% 和 13.02%**；应按原论文口径保留为作者结果，不称本项目验证。
- DCASE 2026 Text Anchors 在 −20 dB 警笛检测，作者报告**召回率 51.2% / 特异度 96.4%**。其 ESC 分类数字不能与 SED 指标合并。
- EAD-SED（2025）作者在 DESED / WildDESED 显示噪声越强时相对优势越明显；此处不杜撰具体分档性能。

## 对 DAS 光纤听诊的研究假设
1. 噪声感知训练有望降低同频段金属振动/警笛等干扰引起的误检，但与 SED/ASD 学术基准差异较大。
2. 如果目标具有明显局部窄带、调制和周期结构，动态时频模型可能改善低局部 SNR 召回。
3. 目标条件分离仅作低置信复核比所有片段强制分离更值得先验证，防止 Clean 退化、分离幻觉与成本膨胀。

**证据等级**：作者报告 != 本仓库复现 != DAS 现场验证；未核对全文的指标一律标注“待核验”。
