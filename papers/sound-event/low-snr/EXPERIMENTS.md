# 低信噪比检测复现与 DAS 迁移实验建议

## 研究问题
在同一个基础网络、相同数据量、固定测试集以及相同阈值选择规则下，对比噪声增强、Noise-aware、动态时频与条件分离是否改善低 SNR 异常事件的召回及误报。

## 数据协议
- SNR：Clean、+10、+5、0、−5、−10、−15、−20 dB；明确以目标事件有效时间区间和频带/全带计算的定义。
- 使用真实背景噪声 + 合成混合两条评估线；记录噪声源、设备、位置、运行工况与混合随机种子。
- 包含目标存在、仅噪声无目标、相似干扰与目标重叠、未知干扰等四类样本。
- 训练/验证/测试严格分离项目、探测器、时间和噪声录音；测试集冻结，不能用测试集选择阈值。
- DAS 多探测器需要评估耦合差异、传播时延、信号泄漏；参考通道不能预设为纯噪声。

## 对照组
| 组别 | 模型 | 控制变量 |
|---|---|---|
| B0 | ResNet18 / 原始谱图检测 | 基线 |
| B1 | B0 + 匹配噪声增强 | 同主干、预算 |
| B2 | B0 + Noise-aware 对比/双视角训练 | 尽量同主干、预算 |
| B3 | B0 + 动态时频模块 | 同训练数据 |
| B4 | B0 + 目标存在性/计数辅助头 | 同训练数据 |
| B5 | B0 + 条件分离/融合复核 | 统计延迟、分离假阳性 |
| B6 | 优胜模块组合 | 消融交互效应，防止只看堆叠提升 |

## 评估指标
- 事件级 F1、PSDS、事件起止误差；若只有 clip 标签，须明确不提供未经标注支持的事件级指标。
- 固定每小时误报预算下的 Recall、pAUC、PR-AUC；按 SNR、噪声类型、项目、探测器、事件长度分组。
- 统计重复随机种子置信区间，跨项目独立 bootstrap；展示最差项目及性能下降，而非仅平均值。
- 记录训练和推理成本、目标不存在时虚假事件率、Clean 输入退化。

4. 错误案例音频/谱图、强干扰误报审计和事件级分析。
