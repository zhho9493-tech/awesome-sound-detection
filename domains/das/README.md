# DAS / 分布式光纤声学检测

重点：皮带输送机托辊异常、分布式传感、时空一致性、旋转周期声、非目标干扰。

研究主线：
- 光纤探测信号与常规空气声学的域差异
- 跨项目/通道/探测器/时间泛化
- 片段分类到事件聚合
- 空间、时间、周期性物理约束
- 运行状态识别与探测器自适应阈值
- 未知类别拒识、持续性和异常强度评估
- 位置级正常基线、健康状态演化与 RUL/PHM
- 工业音频/DAS 自监督预训练与跨项目适配

本目录仅存公开知识，不包含用户或公司的非公开项目数据。

## 技术时间线

| 时间 | 技术主线 | 对工业 DAS 的意义 |
|---|---|---|
| 2010s–2022 | 光纤解调、事件检测、地震/周界/管线为主 | 核心关注“能否稳定采到分布式声振信号” |
| 2023–2024 | 深度学习事件识别与多通道时空建模 | DAS 从信号可视化向自动识别转移 |
| 2025-12 | Near real-time channel selection | 开始显式处理通道质量、SNR 与计算规模 |
| 2026-03 | DASNet：半监督多类 + 时空框/分割 | 从单通道 clip 分类向多通道事件检测升级 |
| 2026-04 | 物理模型 + 神经网络空间标定 | 物理几何、位置标定与学习模型开始融合 |
| 2026-07 | 真实 DAS 数据集与检测/定位基准 | 真实工况、多通道、跨场景基准更受重视 |
| 2026-09 | SeisBench DAS 标准化框架 | 数据、标签、模型接口标准化，利于跨项目复现 |
| 2026-09 | 既有通信光纤机会与挑战 | 光纤耦合、偏振、激光相位噪声等部署差异进入主流讨论 |
| 2026-10 | Edge intelligence / ultracompact DAS models | 多任务小模型、边缘部署与实时性进一步前移 |
| 下一阶段 | Health-state / PHM / Foundation Encoder | 从事件识别走向位置长期基线、严重度、跨项目预训练与预测维护 |

## 技术趋势

1. **[全局分类器 → 位置级 baseline + 时空聚合](trends/trend-01.md)**：不同光纤耦合和探测位置必须显式建模。
2. **[10 s clip → 时空事件](trends/trend-02.md)**：多通道框、分割、跟踪比独立 clip 更贴合 DAS 的空间连续性。
3. **[固定探测器 → 通道质量感知](trends/trend-03.md)**：SNR、衰落、耦合质量和 channel selection 会成为前置模块。
4. **[纯数据驱动 → 物理约束 + 数据驱动](trends/trend-04.md)**：空间几何、传播、周期、设备旋转规律开始进入模型。
5. **[单项目模型 → 标准化 + 自监督预训练 + 跨项目适配](trends/trend-05.md)**：统一数据格式和通用 DAS encoder 是重要方向。
6. **[异常/正常 → 严重度/健康状态/RUL](trends/trend-06.md)**：弱异常、持续增强和维护时机比单次分类更有价值。
7. **[离线高精度 → 边缘实时与工程指标](trends/trend-07.md)**：参数量、时延、FP/km/day、漏报率、定位误差将共同决定商业可用性。

## 当前判断 / 待关注

- 近期优先级最高：**跨项目泛化、位置级正常基线、DAS 自监督预训练、事件级时空建模、健康状态推理**。
- 工业皮带机建议统一输出：clip score + baseline deviation + temporal persistence + spatial consistency + operating condition → equipment health state。
- 新论文加入后，需检查它是否改变“时空事件化 / 跨项目预训练 / 物理约束 / 健康状态”四条主趋势。
