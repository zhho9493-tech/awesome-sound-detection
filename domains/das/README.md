# DAS / 分布式光纤声学检测

重点：皮带输送机托辊异常、分布式传感、时空一致性、旋转周期声、非目标干扰。

研究主线：
- 光纤探测信号与常规空气声学的域差异
- 跨项目/通道/探测器/时间泛化
- 片段分类到事件聚合
- 空间、时间、周期性物理约束
- 运行状态识别与探测器自适应阈值
- 未知类别拒识、持续性和异常强度评估

本目录仅存公开知识，不包含用户或公司的非公开项目数据。
