# DAS / 分布式光纤声学检测

重点：皮带输送机托辊异常、分布式传感、时空一致性、旋转周期声、非目标干扰。

研究主线：
- 光纤探测信号与常规空气声学的域差异
- 跨项目/通道/探测器/时间泛化
- 片段分类到事件聚合
- 空间、时间、周期性物理约束
- 运行状态识别与探测器自适应阈值
- 未知类别拒识、持续性和异常强度评估
- 位置级正常基线、健康状态演化与 RUL/PHM
- 工业音频/DAS 自监督预训练与跨项目适配

本目录仅存公开知识，不包含用户或公司的非公开项目数据。

## 当前重点技术趋势

1. 全局分类器 → 位置级 baseline + 时空聚合；
2. clip 级正常/异常 → 设备级严重度/健康状态；
3. DAS 单模态 → DTS、点式声振温、视频、机器人多源融合；
4. 单项目模型 → 自监督预训练、跨项目泛化与现场自适应；
5. 离线 pAUC → FP/km/day、漏报率、定位误差、弱异常提前量等工程指标。
