# 趋势 8：闭集故障分类 → 开集识别与未知干扰拒识

[返回 DAS 技术趋势](../README.md) · **状态：论文问题定义已核对；方法与性能待全文复核** · 2026-11-03

## 结论与适用边界

从固定正常/已知故障类别的闭集分类，向同时处理“已知目标异常、未知故障、未知非目标干扰”的开集诊断扩展，是 DAS 皮带机监测值得验证的方向。**有直接论文实例，不意味着已经证明跨矿山/跨项目的误报率改善。**

## 论文证据

- Huayang Lv 等，[*Toward Open-Set Fault Diagnosis for Belt Conveyors Using Distributed Acoustic Sensing*](https://doi.org/10.1109/JSEN.2026.3709836)，IEEE Sensors Journal 26(16), 23956–23969, 2026。题名、作者与卷期可由[作者团队公开论文目录](https://ruiqingtang.github.io/)核对；本次未逐项验证论文算法结构、开放集评价数值或 PDF 可下载性。
- 关联迁移方法：[MIRA](https://doi.org/10.3390/s25247469)，Sensors 25(24), 7469, 2025，使用**麦克风和加速度计**构建无监督 Transformer 重构异常检测与位置估计。**非 DAS 论文**；能否处理光纤未知干扰需独立实测。

## 分析链路（证据和推断分离）

1. **实际问题**：训练集中不可能穷尽所有托辊故障状态与现场干扰；闭集 softmax 必须给已知类分配概率。
2. **直接证据**：2026 年已有题名和研究任务明确指向 DAS 皮带机开集故障诊断的 IEEE 论文。
3. **工程推断**：可以引入未知类拒识、OOD 评分与事件级证据聚合，但不能仅凭论文标题宣称“未知干扰误报已解决”。
4. **关键边界**：未知故障可能应该报警，未知非目标噪声应该抑制；把二者统一拒识可能反而降低召回率。

## 建议实验（可证伪）

| 实验组 | 输出机制 | 关注指标 |
|---|---|---|
| A：现有闭集分类 | 已知故障类别分数 + 事件聚合 | 已知异常 Recall、Precision、FP/km/day |
| B：置信度拒识 | max-softmax / energy score | AUROC-OOD、FPR95、未知异常漏报 |
| C：距离/原型拒识 | Prototype distance / Mahalanobis | 跨项目拒识稳定性及校准变化 |
| D：两类未知分流 | 未知目标候选保留报警、已知非目标抑制、待复核队列 | 未知故障发现率、人工复核量、设备级误警 |

- 固定项目级独立测试集，避免不同项目/探测器/时间段信息泄漏。
- 分别构造“未知托辊故障”“未知非目标干扰”“已知故障跨项目偏移”集合，避免把三者混为一谈。
- 分 clip、30 min 事件和设备位置三个层次汇总；使用同等事件阈值或完整 PR 曲线比较。
- 若拒识提高 OOD 指标但显著降低未知目标故障召回或无法跨项目稳定校准，不能升级趋势置信度。
