## 技术时间线

| 阶段 | 技术主线 | 典型能力 |
|---|---|---|
| 传统阶段 | 听音、相关定位、频谱阈值 | 检测“是否泄漏”、估计位置 |
| 2018–2022 | 机器学习/深度学习分类 | 从手工频谱特征转向 CNN/SVM/时频图分类 |
| 2022–2024 | IoT + 多传感器 + 边缘监测 | 连续在线监测、远程告警、环境数据融合 |
| 2024–2025 | 复杂背景噪声鲁棒性 | 更关注工业噪声、工况变化、弱泄漏和跨管网泛化 |
| 2025–2026 | 自适应波形提取、异常类型识别 | 从单纯检测扩展到阀门/气体泄漏类型识别和严重度估计 |
| 下一阶段 | Physics-informed + Multimodal | 将传播物理、压力/流量、声学/超声/图像联合用于定位和泄漏率估计 |

## 技术趋势

1. **[检测 → 定位 → 泄漏率/严重度估计](trends/trend-01.md)**：业务价值逐步从“发现问题”走向“量化问题”。
2. **[单传感器 → 多模态](trends/trend-02.md)**：声学、超声、压力、流量、图像/声学成像的融合会增强鲁棒性。
3. **[实验室高精度 → 现场跨域泛化](trends/trend-03.md)**：管材、压力、埋深、环境噪声和安装方式造成显著域偏移。
4. **[固定特征 → 自适应波形/表征学习](trends/trend-04.md)**：弱泄漏需要更强的局部时频特征和自适应提取。
5. **[黑盒分类 → 物理约束推理](trends/trend-05.md)**：传播速度、衰减、管网结构和流体机理可用于降低假警。
6. **[单点检测 → 长期健康监测](trends/trend-06.md)**：未来更可能与资产管理、维修优先级和风险预测结合。

## 当前判断 / 待关注

- 水管方向优先：弱泄漏、跨管材/压力泛化、互相关定位与深度表征融合；临时麦克风阵列可关注反射/几何自校准，但室内 RIR 方法需在管壁耦合和室外场景独立验证。
- 气体方向优先：超声 + 声学成像 + 泄漏率估计 + 工业噪声鲁棒。
- 新增论文后，应判断其是否推动“多模态、物理约束、定量估计、跨域泛化”中的任一趋势。
