# Industry Watch / 业界动态

聚焦智能声学、DAS、输送机监测、工业异常检测、水管及气体泄漏。

资源类型：企业产品、项目落地、客户案例、专利、论文、招聘、融资与技术路线。

## 专题入口

- [DAS 皮带机企业动态时间线](das-conveyor-timeline.md) — 国内/海外企业、招标项目、客户案例、商业化路径与技术趋势
- `weekly/` — 周期性行业简报归档

每条记录须有发生日期、发布日期、机构、原始链接、技术摘要、可信度与业务相关性。周期总结放入 `industry/weekly/`。

### DAS 皮带机长期重点跟踪

华为、海纳科技、海康威视、讯飞潮汐力、光格科技、国家能源集团相关项目，以及 Mining3 / PositioNXT / Vuuma、REMA TIP TOP / Terra15 等海外路线。

重点指标：FP/km/day、漏报率、定位误差、长期稳定性、弱异常提前量、跨项目泛化和设备级健康状态。
