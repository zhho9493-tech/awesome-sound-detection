## 技术时间线

| 时间 | 技术演进 | 对工业声学的潜在意义 |
|---|---|---|
| 传统方法 | 声学特征 + 类别判别 | 识别状态或异常类型 |
| 2025–2026 | 物理约束的时序表征与连续状态估计 | 从分类分数走向可解释物理量 |
| 2026-11 | SonoDyno 多尺度谐波阶次 + 旋转动力学约束 | 为旋转设备转速、负载强度推理提供可借鉴方法 |
| 下一阶段 | 物理状态 + 声学异常 + 长期健康轨迹 | 需在目标设备和跨项目数据上验证 |

## 技术趋势

1. **类别识别 → 连续状态估计**：声学模型可尝试直接回归速度、负载或状态强度。
2. **纯数据拟合 → 物理约束时序解码**：旋转动力学、周期性和工况变化可作为结构先验。
3. **单一谱图 → 多尺度频谱/阶次特征**：融合不同分辨率捕捉短时瞬态与稳定谐波。

## 当前判断 / 待关注

- 对 DAS 托辊监测，优先比较多尺度阶次特征、运行状态条件化与物理平滑的强度回归模型。
- 需严格区分“原论文发动机实验结果”与“托辊监测可迁移假设”。
