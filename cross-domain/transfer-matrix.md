# 跨领域算法迁移矩阵

| 来源领域 | 方法 | 声学迁移点 | 验证重点 |
|---|---|---|---|
| 声纹识别 | ECAPA-TDNN | 强判别性 Embedding | 与 ResNet 统一条件比较 |
| 声纹识别 | 域适应 | 跨传感器与项目 | 留一项目评估 |
| 人脸识别 | ArcFace | 类间角度间隔 | pAUC、校准与误报 |
| 人脸识别 | Sub-center ArcFace | 类内多模态与错标 | 不同原型数的消融 |
| 图像异常 | PatchCore | 时频局部异常检索 | 内存、误报、异常定位 |
| 图像异常 | PaDiM | 局部特征分布建模 | 不同域下的稳定性 |
| 基础模型 | CLAP / BEATs | 预训练迁移 | 线性探针 vs 全量微调 |
| 物理约束 | 周期/时空一致性 | 事件级判断 | 片段级 vs 时序聚合 |

以上均为可研究的**迁移假设**，不是已经验证的性能提升。
