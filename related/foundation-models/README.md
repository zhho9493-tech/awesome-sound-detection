## 技术时间线

| 阶段 | 技术主线 | 代表性变化 |
|---|---|---|
| 2021–2022 | Audio SSL / BEATs 类预训练 | 大规模无标签音频预训练成为通用特征底座 |
| 2022–2023 | CLAP / Audio-Text Alignment | 音频与文本语义空间对齐，支持 zero-shot 与检索 |
| 2023–2024 | Vision/Multimodal Foundation Features | DINOv2 等强 encoder 证明“冻结特征 + 轻量下游”具有高迁移价值 |
| 2024–2025 | Adapter / LoRA / Retrieval Augmentation | 参数高效适配和外部记忆成为部署友好路线 |
| 2025–2026 | Industrial Foundation Models | 开始面向多模态工业信号、不同采样率、不同设备建立统一表征 |
| 2026 | Audio-LLM / Reasoning RL | 从“编码/检索”进一步走向音频理解、推理、证据组织和诊断解释 |
| 2026-10/11 | Audio-LLM 评估校准与跨模态冲突 | 研究开始量化 Audio-LLM 感知偏差和模态不一致风险，强调证据可靠性而非仅增加模态 |
| 下一阶段 | Domain-specific Foundation Encoder + Agent | 通用 encoder、检索库、工具调用和物理/状态模型组合成工业智能体 |

## 技术趋势

1. **[任务专用 CNN → 通用预训练 Encoder](trends/trend-01.md)**：训练重心从“从零训练分类器”转向“选择/适配基础表征”。
2. **[监督预训练 → Self-supervised / Multimodal pretraining](trends/trend-02.md)**：未标注工业数据价值显著提升。
3. **[全量微调 → Adapter/LoRA/Linear Probe](trends/trend-03.md)**：跨项目快速适配和防遗忘更易工程化。
4. **[单一 embedding → Retrieval-Augmented](trends/trend-04.md)**：历史样本、相似案例和 prototype 可直接参与推理。
5. **[Audio-only → Audio-Text / Multimodal](trends/trend-05.md)**：文本知识、维修记录和设备元数据可与音频联合；但跨模态证据冲突可能使 Audio-LLM 退化，需显式一致性检查与回退机制。
6. **[预测模型 → Reasoning model / Agent](trends/trend-06.md)**：模型开始输出“证据—判断—建议”，而不只是概率。
7. **[通用大模型 → 行业基础模型](trends/trend-07.md)**：工业采样率、传感器、设备物理差异决定专用预训练仍然必要。

## 当前判断 / 对工业声学迁移

- 建议长期基线：专用 ResNet vs 冻结预训练 encoder vs 全量微调 vs Adapter/LoRA vs DAS/工业音频自监督预训练。
- 对海量未标注工业数据，最值得投入的是 **domain-specific self-supervised pretraining**。
- **2026-11 新证据**：Audio-LLM 质量评估存在零样本偏差，LoRA 适配可改善特定任务；多模态情绪证据不一致与错误率上升相关。建议在 DAS 工况/文本融合中增设 conflict-aware gating 和 calibration 对照。
- 新增论文后，应判断是否改变“预训练底座 / 轻量适配 / 检索增强 / 推理智能体”四条趋势。

## 2026-11-04 每日增量（对应 11-03 公告）

- [新增 1 篇：长上下文 SpeechLLM KV 检索（另 2 篇已在年度索引，未重复收录）](arxiv-cs-sd-2026-11-03.md)。
- **技术时间线补充（2026-11）**：从一般音频-文本对齐进一步到**同一录音内部的语言陈述与声学证据冲突测试**；另有空间基础模型通过冻结主干与 LoRA 路由完成多任务适配。

## 2026-11-05 每日增量（对应 11-04 公告）

- [新增 4 篇：空间音频 Agent、置信聚合、长音频证据定位、可核查推理](arxiv-cs-sd-2026-11-04.md)。
- **技术时间线（2026-11）**：Audio-LLM 从端到端回答走向**证据定位 → 多候选校准 → 工具调用/可核查推理**；SciPhi-Chat 与 ReListen 等提供具体方法证据。
- **技术趋势修订**：Retrieval-Augmented 不仅检索历史样本，也可以主动回听原始录音局部片段；Agent 输出须保留可验证声学证据和不确定性。
- **当前判断**：DAS 复核可尝试“事件索引 → 精听证据 → 置信聚合 → 可追溯结论”，仍为迁移假设。

## 2026-11-07 每日增量（对应 11-06 公告）

- [新增 3 篇：任务路由蒸馏、流式推测监听、子带时域分离](arxiv-cs-sd-2026-11-06.md)。
- **技术时间线（2026-11）**：基础音频模型在多任务蒸馏与流式推理中进一步强调任务条件化的计算分配和结果校验；多频带分离仍属既有技术路线的结构改进，不单独确立新范式。
- **技术趋势复核**：维持“预训练底座 / 轻量适配 / 检索增强 / 可核查推理”主线，补充“低延迟蒸馏与推测执行须验证真实声学输入”的工程约束。
- **当前判断 / 待关注**：DAS 10 秒片段的基础模型复核可探索压缩与多频带表征，但应首先检验异常事件保真、设备级误报和跨项目泛化；所有迁移均为研究假设。

## 2026-11-10 每日增量（对应 11-09 公告）

- [新增 3 篇：AnomSep 可试听异常解释、AudioSphere 空间自监督、IRIS-Embed 指令条件检索](arxiv-cs-sd-2026-11-09.md)。
- **技术时间线（2026-11）**：从单通道通用音频 SSL 延伸到**多通道空间—声学联合掩码预训练**；异常检测从单标量分数扩展到**可试听异常残差证据**，并以异常残差能量关联评分。
- **技术趋势复核**：增加“黑盒异常分数 → 可试听/可核查异常声证据”与“统一音频嵌入 → 指令条件层选择/检索”两个细化方向；空间 SSL 为新任务设定，尚不足以断言 DAS 部署性能收益。
- **当前判断 / 待关注**：优先比较 ResNet 基线与正常字典+异常分离评分、异常音频可听性；多通道 DAS 可研究空间 SSL，但 Ambisonics 与 DAS 物理结构不等价。以上均为工业迁移研究假设。

- [新增 3 篇：LAION-Audio-XL 大规模音频文本预训练、MachEar 非人耳机器听觉、LongCap 长时带时间戳音频描述](arxiv-cs-sd-2026-11-10.md)。
- **技术时间线（2026-11）**：从人类可听声音基础模型延伸至**异构振动/非传统采样信号的专用前端适配**；长音频理解进一步从短片段caption走向小时级结构化事件时间线。大规模数据清洗与规模规律属于既有预训练范式强化。
- **技术趋势复核**：强化“通用模型 → 传感器/任务特定前端适配”及“音频问答 → 可定位长时事件证据”；不将Audio-LLM的机器听觉基准效果外推为DAS性能。
- **当前判断 / 待关注**：对比冻结CLAP/Audio-LLM、DAS专用编码器、轻量Adapter；长时caption先用于事件级复核而非直接报警。均为迁移研究假设。

## 2026-11-12 每日增量（对应 11-11 公告）

- [新增 2 篇：AURA 多声源空间语义绑定、冻结基础模型属性条件检索](arxiv-cs-sd-2026-11-11.md)。
- **技术时间线（2026-11）**：空间音频理解从分离语义与方向编码走向**冻结通用音频编码器 + 显式通道线索 + 目标声源语义绑定**；条件检索则是已有轻量适配/度量学习路线的细化。
- **技术趋势复核**：强化“通用表征 → 任务/属性条件化读取”与“多源场景回答 → 目标身份—空间证据一致性”，暂不改变原有七条主趋势的优先级。
- **当前判断 / 待关注**：DAS优先验证多探测器异常位置与事件身份绑定、按工况/故障属性条件检索；双耳空间音频与DAS传感物理不同，以上均为研究假设。

## 2026-11-14 每日增量（对应 11-13 公告）

- [新增 2 篇：TRACE 声源级反事实证据审计、DeALR 测试时声学片段回溯](arxiv-cs-sd-2026-11-13.md)。
- **技术时间线（2026-11）**：Audio-LLM 从“答案准确率/一次性编码”走向**声源级反事实证据排序审计 + 推理时声学片段主动回溯**；属于可核查推理方向的新评估机制。
- **技术趋势复核**：强化现有“预测 → 可核查推理/Agent”主线，不增加未经多篇验证的独立主趋势；需区分正确答案与可靠证据。
- **当前判断 / 待关注**：DAS 报警复核可设计干扰源移除/替换、关键时间段回听与证据一致性测试；注意分离伪迹和工况差异。均为研究假设。
