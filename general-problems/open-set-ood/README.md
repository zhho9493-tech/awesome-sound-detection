# 开放集识别与分布外检测（OOD）

## 问题边界

开放集识别要求在识别已知类的同时拒绝未知类；OOD 检测更关注输入是否偏离训练分布。异常检测、错误检测和开放集分类相邻但不等价。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 注意事项 |
|---|---|---|---|
| 开放集概率 | 重校准分类层并显式分配“未知”概率 | [OpenMax](https://arxiv.org/abs/1511.06233) | 依赖已知类激活空间结构 |
| 最大软最大概率 | 以最大 softmax 概率作为未知分数 | [MSP Baseline](https://arxiv.org/abs/1610.02136) | 简单但神经网络可能对未知样本过度自信 |
| 温度与扰动 | 温度缩放结合小输入扰动拉开 ID/OOD 分数 | [ODIN](https://arxiv.org/abs/1706.02690) | 超参可能依赖特定 OOD 数据 |
| 外部异常暴露 | 用辅助异常数据学习降低 OOD 置信度 | [Outlier Exposure](https://arxiv.org/abs/1812.04606) | 辅助异常不能覆盖所有未知类型 |
| 能量分数 | 用分类 logits 的能量代替归一化概率 | [Energy-based OOD](https://arxiv.org/abs/2010.03759) | 阈值必须在独立验证数据上选择 |

## 评估协议

至少报告 AUROC、AUPR、FPR@95TPR；开放集分类再报告 OSCR 和已知类准确率。分别构造近 OOD 与远 OOD，避免只用容易区分的异构数据集。

## 声音任务落地

将未知事件、未知设备和纯背景分开评测。先保留 MSP 与能量分数基线，再考虑异常暴露；部署阈值应按场景成本和目标误报率选择，而不是只追求 AUROC。
