# OOD（Out-of-Distribution）独立问题方向

> 维护日期：2026-11-10｜近一年窗口：2025-11-10 至 2026-11-10｜范围：音频 / 工业异常声学 / DAS；经典论文另见 [原开放集与 OOD 页面](../open-set-ood/README.md)。

**核心定义**：OOD 判断输入是否偏离参考分布；开放集识别（OSR）判断是否属于训练时未见的语义类别；机械故障异常（AD）判断设备健康状态。**OOD ≠ 故障**，**跨域分布偏移 ≠ 新故障**。

## 核心问题与技术趋势

1. **输出置信度 → 特征/局部密度**：MSP、MaxLogit、Energy 成本低；kNN、Mahalanobis、多原型可表达更复杂的已知声学分布。
2. **单一未知分数 → 正常性与已知性双评分**：分别建立正常参考库与全已知类别参考库，以区分新型干扰、新项目正常声音及新故障候选。
3. **静态拒识 → 跨域分数校准**：针对项目/工况偏移，比较 pooled、分项目及少量目标域正常样本的校准，防止新域正常样本误拒。
4. **片段分数 → 事件级可靠性**：结合 DAS 10 秒片段、持续性、相邻探测器空间定位及旋转周期证据，再作候选事件决策。
5. **未知拒识 → 未知发现及持续学习**：高 OOD 样本经去重、聚类、人工复核和固定回归测试后才能进入类别或正常库。

## DAS 适用性与推荐实验

| 目标 | 首选方案 | 必须防止的错误 |
|---|---|---|
| 发现未知托辊故障 | 冻结 ResNet18 的 kNN / Multi-Prototype / Mahalanobis；双参考库 | 高 OOD 不自动等于故障报警 |
| 抑制未知干扰误报 | OOD + 已知干扰分类 + 事件级时空证据 | 将未知故障误当干扰抑制 |
| 跨项目泛化 | 域感知校准 + 可信目标域正常库 | 将新项目正常声音误判未知故障 |
| 低 SNR | 对照 Noise-aware 表示和频带结构化 Backbone | 模型将噪声变化当成机械故障 |

**第一轮固定模型比较**：后验概率、MSP、MaxLogit、Energy、Cosine Prototype、Multi-Prototype、Shrunk Mahalanobis、kNN、局部密度 kNN、融合分数。统一数据切分和阈值校准；未知故障整类留出、未知干扰整类留出、留一项目验证、近 OOD/低 SNR 专门评测。

**指标**：OOD AUROC/AUPR、FPR@95、OSCR、已知异常 pAUC、未知故障事件召回、新项目误报/天、检测延迟。在固定已知故障召回与误报预算下比较增益。原有 30 分钟/5 条报警规则作为固定对照；首轮仅影子模式记录，不修改线上报警。
