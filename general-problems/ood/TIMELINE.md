# OOD 近一年论文时间线

> 2025-11-10—2026-11-10；2026 年收录论文优先按可确认的首次公开日排序，只有年份可核验者单独列出。

- **2026-06-03** — [Open-Set Event Recognition System Using Self-Supervised Contrastive Learning in Distributed Fiber Acoustic Sensing](https://doi.org/10.1109/JIOT.2026.3699775)：自监督对比学习、一致性、双层阈值、Center Loss、未知聚类；OOD/开放集核心。
- **2026-06-09** — [Anchoring the Unknown: Open-Set Model Attribution via Proxy-Anchor Learning](https://arxiv.org/abs/2606.10758)：Proxy-Anchor 度量学习、嵌入距离和未见 TTS 来源拒识；OOD/开放集核心。
- **2026-07-05** — [Training-Free Model Selection and Domain-Aware Score Calibration for First-Shot Anomalous Sound Detection](https://arxiv.org/abs/2607.04526)：冻结特征、域分位数校准、无需目标域异常标签的模型选择；OOD/开放集核心。
- **2026-07-12** — [ECHOv2: Two-Level Band-Splitting Representation Learning for Anomalous Sound Detection](https://arxiv.org/abs/2607.10596)：频带结构化自监督、跨频带蒸馏及冻结特征评测；关联性方法。
- **2026-07-14** — [UD-ASD: A Unified Diffusion Model for Anomalous Sound Detection](https://arxiv.org/abs/2607.12576)：条件扩散重构、GMM 重构误差密度；关联性方法。
- **2026-08-01** — [Anomalous Sound Detection Meets Noise-Aware Self-Supervised Learning](https://arxiv.org/abs/2608.00447)：双通道噪声感知自监督表示，BEATs/EAT/Dasheng；关联性方法。
- **2026-09-03** — [Cross-Domain Few-Shot Recognition in Distributed Optical Fiber Acoustic Sensing based on Contrastive Learning with Generative Data Augmentation](https://doi.org/10.1109/JIOT.2026.3730549)：生成增强、对比学习、少样本适配及温度/不确定性开放集评价；OOD/开放集核心。

## 2026 年（准确发表日未充分核实）

- **2026** — [Toward Open-Set Fault Diagnosis for Belt Conveyors Using Distributed Acoustic Sensing](https://doi.org/10.1109/JSEN.2026.3709836)：开放集故障诊断；直接相关。
