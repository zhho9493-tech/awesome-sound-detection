# 对抗鲁棒性

## 问题边界

对抗样本是在明确威胁模型下，刻意寻找能使模型出错的微小扰动。它不同于混响、背景噪声、编解码失真等自然分布偏移；两者应分别评测。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 注意事项 |
|---|---|---|---|
| 快速梯度攻击 | 沿输入损失梯度符号构造一步扰动 | [FGSM](https://arxiv.org/abs/1412.6572) | 主要是快速基线，不能单独证明鲁棒性 |
| 鲁棒优化 | 用多步 PGD 近似内层最坏情况并对抗训练 | [PGD Adversarial Training](https://arxiv.org/abs/1706.06083) | 计算昂贵且可能损失干净准确率 |
| 准确率—鲁棒性权衡 | 显式优化自然误差与鲁棒误差边界 | [TRADES](https://arxiv.org/abs/1901.08573) | 权衡系数需按风险场景设定 |
| 可认证鲁棒性 | 随机平滑为一定半径内预测给出概率保证 | [Randomized Smoothing](https://arxiv.org/abs/1902.02918) | 保证依赖噪声模型且推理成本高 |

## 评估协议

明确攻击者能力、范数、扰动预算、白盒/黑盒和目标/非目标攻击；至少使用多步强攻击并检查梯度遮蔽。音频还需区分数字域扰动与扬声器—麦克风物理播放攻击。

## 声音任务落地

先建立干净、自然噪声和对抗扰动三套测试。PGD 对抗训练是标准防御基线，但若系统面临物理攻击，应加入房间响应、重录制和感知约束，不能把数字域结果直接解释为现实安全性。
