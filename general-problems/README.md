# 深度学习通用问题专题

本专题不按具体声学任务划分，而按模型在真实数据中反复出现的失效模式组织。每个页面包含：问题边界、经典解决方案、代表论文、评估协议、常见误区，以及在声音事件检测、异常声音检测和工业声学中的落地建议。

## 问题导航

| 问题方向 | 典型症状 | 建议先做的基线 | 专题 |
|---|---|---|---|
| 跨域泛化 | 换设备、场景或工况后性能骤降 | ERM + 严格留域验证 | [跨域泛化](domain-generalization/README.md) |
| 少样本学习 | 新类别只有少量标注 | 预训练 + 线性探测/原型网络 | [少样本学习](few-shot-learning/README.md) |
| 长尾与类别不平衡 | 头部类很好、尾部类几乎失效 | 重采样 + 类别均衡损失 | [长尾学习](long-tail-learning/README.md) |

## 选型顺序

1. 先确定失效模式和数据切分单位，避免把同一设备、录音或工况泄漏到训练与测试。
2. 保留普通 ERM、交叉熵和预训练微调作为强基线，再加入一种经典方法定位收益来源。
3. 同时报告总体指标与分组指标；长尾看头/中/尾类，跨域看逐域，持续学习看逐阶段。
4. 将“检测未知”“置信度可靠”“抵抗攻击”分开评估，它们不是同一个问题。
