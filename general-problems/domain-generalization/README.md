# 跨域泛化（Domain Generalization）

## 问题边界

训练时可见若干源域，部署时目标域不可见。若训练阶段已经使用无标签或有标签目标域数据，则属于域适配而非严格域泛化。声音任务中的“域”通常是设备、采集地点、信噪比、工况或人群。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 适用边界 |
|---|---|---|---|
| 经验风险最小化 | 合并源域训练，配合强数据增强 | [DomainBed](https://arxiv.org/abs/2007.01434) | 必须作为强基线；模型选择比复杂算法更关键 |
| 统计对齐 | 对齐不同域的特征协方差 | [Deep CORAL](https://arxiv.org/abs/1607.01719) | 域差异主要表现为统计偏移时有效 |
| 不变风险 | 学习在各源环境上共享最优分类器的表示 | [IRM](https://arxiv.org/abs/1907.02893) | 依赖合理环境划分；优化和超参敏感 |
| 平坦极小值 | 在训练轨迹中寻找跨域泛化更稳的平坦区域 | [SWAD](https://arxiv.org/abs/2102.08604) | 训练成本上升，但易与 ERM 组合 |

## 评估协议

- 使用 leave-one-domain-out；目标域不得参与调参。
- 同时报逐域结果、平均值、最差域和多随机种子方差。
- 声学任务按原始录音、设备与地点分组切分，不能按短音频片段随机切分。

## 声音任务落地

先建立“预训练编码器 + ERM + 频谱增强”基线，再依次验证统计对齐或平坦极小值。若新设备存在可用无标签数据，应明确改用无监督域适配协议，避免把目标域信息包装成域泛化收益。
