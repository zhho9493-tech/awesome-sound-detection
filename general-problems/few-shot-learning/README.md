# 少样本学习（Few-shot Learning）

## 问题边界

目标是在每个新类别仅有少量标注样本时快速适配。标准协议以 N-way K-shot episode 组织支持集与查询集；若类别不变、只是总体数据少，应先考虑预训练与正则化，而非直接套用元学习。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 适用边界 |
|---|---|---|---|
| 匹配与记忆 | 用支持集与查询样本的注意力相似度分类 | [Matching Networks](https://arxiv.org/abs/1606.04080) | episode 训练分布应接近部署任务 |
| 优化式元学习 | 学到易被少量梯度步快速适配的初始化 | [MAML](https://arxiv.org/abs/1703.03400) | 二阶优化昂贵且对内外层超参敏感 |
| 原型度量 | 用每类支持样本的嵌入均值作为类别原型 | [Prototypical Networks](https://arxiv.org/abs/1703.05175) | 简洁稳健，是首选 few-shot 基线 |
| 关系度量 | 学习比较支持集与查询样本的关系函数 | [Relation Networks](https://arxiv.org/abs/1711.06025) | 数据很少时关系网络也可能过拟合 |

## 评估协议

- 基类与新类严格不重叠；报告不同 N、K 和 episode 数下的均值与置信区间。
- 与“预训练编码器 + 最近中心”“线性探测”“全量微调”比较。
- 声音片段需按原始录音或声源隔离，防止同源片段泄漏。

## 声音任务落地

基础音频编码器已很强时，冻结编码器后做原型分类往往是更可靠的起点；当新类别与预训练域差异很大，再考虑 MAML 式快速适配或参数高效微调。
