# 长尾学习与类别不平衡

## 问题边界

训练样本在类别间高度不均衡，导致模型决策边界偏向头部类。它不同于普通小数据：长尾问题同时涉及先验偏移、表示质量和尾类决策边界。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 注意事项 |
|---|---|---|---|
| 难例聚焦 | 降低易分类样本权重，聚焦困难样本 | [Focal Loss](https://arxiv.org/abs/1708.02002) | 难例可能也是噪声样本 |
| 有效样本数重加权 | 用类别有效样本数替代原始频次 | [Class-Balanced Loss](https://arxiv.org/abs/1901.05555) | 需调节重加权强度 |
| 类别相关间隔 | 为少数类设置更大的分类间隔并延迟重加权 | [LDAM-DRW](https://arxiv.org/abs/1906.07413) | 主要面向单标签分类 |
| 先验校正 | 在 softmax 中显式修正长尾采样带来的梯度偏差 | [Balanced Softmax](https://arxiv.org/abs/2007.10740) | 部署先验变化时需重新校准 |

## 评估协议

除总体准确率外，报告 macro-F1、balanced accuracy、逐类召回率，以及 many/medium/few-shot 分组结果。多标签声音事件还应报告每类 AUPRC，并检查阈值是否按验证集独立选择。

## 声音任务落地

先对比类别均衡采样、Focal Loss 和 Balanced Softmax；若尾类标注本身噪声较多，不应盲目提高权重，应结合标签审计或噪声标签方法。
