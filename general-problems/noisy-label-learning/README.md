# 噪声标签学习

## 问题边界

标签可能来自众包、弱规则、自动标注或不完整事件边界。应区分随机翻转、类别相关噪声、实例相关噪声和漏标；真实音频中的噪声往往不是对称随机噪声。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 适用边界 |
|---|---|---|---|
| 课程学习 | 教师网络选择更可能正确的样本 | [MentorNet](https://arxiv.org/abs/1712.05055) | 依赖课程或干净信息 |
| 双网络互教 | 两个网络互相交换小损失样本 | [Co-teaching](https://arxiv.org/abs/1804.06872) | 小损失不总等同于干净标签 |
| 半监督分治 | 将样本划为干净/噪声后做 MixMatch 式训练 | [DivideMix](https://arxiv.org/abs/2002.07394) | 计算量较大，划分误差会传播 |
| 早期学习正则 | 抑制网络后期记忆错误标签 | [ELR](https://arxiv.org/abs/2007.00151) | 对开放集噪声需单独验证 |

## 评估协议

合成噪声只能用于可控对照，还应保留人工复核的真实噪声测试集。报告不同噪声率、噪声类型、校准表现与干净验证集结果，并记录被过滤样本的类别分布。

## 声音任务落地

声音事件常见漏标和边界偏差，先做样本级/帧级标签审计，再选择算法。若用模型置信度清洗标签，应避免同一模型既生成标签又在同一划分上证明标签质量。
