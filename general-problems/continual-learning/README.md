# 持续学习与增量学习

## 问题边界

模型按时间接收新任务、新类别或新域，并需在学习新知识时保留旧能力。需明确 task-incremental、class-incremental 或 domain-incremental 设置，以及推理时是否提供任务标识。

## 经典解决方案

| 方法族 | 核心思想 | 代表工作 | 适用边界 |
|---|---|---|---|
| 蒸馏保留 | 用旧模型输出约束新模型 | [Learning without Forgetting](https://arxiv.org/abs/1606.09282) | 新旧数据分布差异大时蒸馏会受限 |
| 参数正则 | 降低对旧任务重要参数的更新幅度 | [EWC](https://arxiv.org/abs/1612.00796) | 任务多时约束可能累积过强 |
| 样本回放 | 保存少量旧样本并维护类别原型 | [iCaRL](https://arxiv.org/abs/1611.07725) | 需明确存储与隐私预算 |
| 梯度约束 | 用记忆样本约束更新不损害旧任务 | [GEM](https://arxiv.org/abs/1706.08840) | 优化与存储开销较高 |

## 评估协议

报告每阶段准确率矩阵、最终平均准确率、平均遗忘、前向/后向迁移和内存预算。必须与联合训练上界、顺序微调下界及等预算回放基线比较。

## 声音任务落地

设备和工况持续新增时，回放通常是最透明的基线。若原始音频不可存储，可比较特征回放、原型回放与蒸馏，但应同时报告隐私、存储和推理成本。
